🎯 Review Sentiment Analyzer: English Text Sentiment Analysis 🐍☕
✨ Overview
This project is my first multi-language application, designed to perform sentiment analysis on customer or user reviews. Given a text review, the application provides an output classifying the sentiment as Good 👍, Bad 👎, or Neutral 😐.

Python Part: The core sentiment model, trained and saved as a pickle file.

Java API: Serves the model prediction to the web frontend via a RESTful endpoint.

🚀 Key Features
Real-time Prediction: Get instant sentiment results for any review input. ⚡

Pickle-Powered Model: Loads a pre-trained sentiment classification model for rapid inference. 🧠

Cross-Language Integration: Demonstrates a clean workflow between Python (data science) and Java (enterprise API). 🔗

Simple Web Interface: Easy-to-use form for submitting text reviews. 🌐
